# Shortcuts

Every key and mouse action Studio responds to, by where it works. Keys use <kbd>Ctrl</kbd> on
every system, Mac included (not <kbd>Cmd</kbd>), except where a row says otherwise. They don't
fire while you type in a field.

## Anywhere

| Keys | Action |
| --- | --- |
| <kbd>Shift</kbd>+<kbd>N</kbd> | New showfile ([Showfiles](/rig/showfiles#starting-a-show)) |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | Load a showfile |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Save the show locally |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> | Export the show as a file |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>V</kbd> | Visualizer settings |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>O</kbd> | Outputs |
| <kbd>Space</kbd> | Pause or resume the show ([Playing a show](/programming/playback#the-clock)) |

## Popups

| Keys | Action |
| --- | --- |
| <kbd>Enter</kbd> | Confirm (the popup's **OK**, **Create**…), when it's enabled |
| <kbd>Escape</kbd> | Cancel and close |

## Lists

Fixture pools, the patch bay, a popup's lists, an effect's channels.

| Action | Result |
| --- | --- |
| Click | Select an item |
| <kbd>Ctrl</kbd>+click (<kbd>Cmd</kbd>+click on a Mac) | Add an item to the selection, or take it out |
| <kbd>Shift</kbd>+click | Select every item from the selected one to this one (within one universe) |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Select the item above or below |
| <kbd>Delete</kbd> or <kbd>Backspace</kbd> | Delete the selection, after a confirmation (the list must have focus: click in it first) |
| Click an item's trash icon | Delete it, after a confirmation (with the whole selection when the item is part of it) |
| <kbd>Escape</kbd> | Clear the selection |
| Click an item's box, or the item, in a list with boxes | Tick or untick it; **Check All** ticks or unticks every item shown |
| Drag an item by its grip (the dots at its far right: fixture pools, an effect's fixtures) | Move it; the other items slide apart where it will land. <kbd>Escape</kbd> cancels. Not while a search is typed |
| Type in **Search items** | Show only the items whose name matches |

## Fields

| Keys | Action |
| --- | --- |
| <kbd>Enter</kbd> | Apply what you typed (also applied when you leave the field) |
| <kbd>↑</kbd> <kbd>↓</kbd> | In a number field: one step up or down |
| Arrow keys | On the colour picker's hue ring or colour square: move it; with <kbd>Shift</kbd>, ten steps at a time |

## Cue Pool, Group Pool, Chases

| Action | Result |
| --- | --- |
| Double click an empty cue slot | Create a cue ([Scenes](/programming/scenes#creating-a-cue)) |
| Click a cue's body / its name | Play or stop it / select it without playing |
| Drag a cue to an empty slot | Move it |
| <kbd>Delete</kbd> or <kbd>Backspace</kbd> | Delete the selected cue (cue pool), the selected group after a confirmation (group pool), or the open chase, at once (chase view) |
| Double click an empty chase slot | Create a chase |

## Chase Timeline

| Action | Result |
| --- | --- |
| Double click a lane | Add a cue item there |
| Drag an item / its right edge | Move it / resize it |
| Right click an item | Remove it |
| Drag up or down on the ruler | Zoom; double click the ruler to reset |

## Visualizer

| Action | Result |
| --- | --- |
| Drag (left button) | Orbit around the stage |
| Drag (right button) | Pan |
| Scroll | Zoom |
| <kbd>T</kbd> | Transform controls: move ([Placing fixtures](/interface/visualizer/#placing-fixtures)) |
| <kbd>R</kbd> | Transform controls: rotate |
| <kbd>H</kbd> | Hide the transform controls (keep the outline) |
| <kbd>Escape</kbd> | Clear the outline |
